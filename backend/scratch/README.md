# Scratch Scripts

This folder is for local, ad-hoc scripts (for probes, smoke runs, and one-off investigations).

Rules:
- Do not treat scripts here as production-safe.
- Do not run scripts here against production data unless you intentionally opt in.
- If a script is useful long-term, promote it into `backend/src/scripts/` with proper naming and validation.

This directory is gitignored except for this README.
